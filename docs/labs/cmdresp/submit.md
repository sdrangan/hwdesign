# Submission

## Your course repository

This project uses your course repository, `hwdesign-work`. If you have not
created it yet, follow [Your course repository](../../support/repo/work.md).
The project uses two folders in it:

```
hwdesign-work/
└── cmdresp/
    ├── inclass/
    │   ├── prompt.md
    │   ├── results.md
    │   └── ...            # what the agent built
    └── takehome/
        ├── prompt.md      # ends with its revision history
        ├── results.md
        └── ...
```

## What to submit

All four parts are under **Command-Response Mini-Project** in the LLM grader.

| Part | Paste into the grader |
| --- | --- |
| 1. In-class prompt | The text of `cmdresp/inclass/prompt.md` |
| 2. In-class implementation | The text of `cmdresp/inclass/results.md` |
| 3. Take-home prompt | The text of `cmdresp/takehome/prompt.md` |
| 4. Take-home implementation | The link to `cmdresp/takehome/` in your repository |

You can submit each part as many times as you like. Use the feedback: the
grader is checking the same things your agent needed to know.

For part 4, set the timeout in the grader's preferences to at least 100
seconds, since the grader has to read your repository.
